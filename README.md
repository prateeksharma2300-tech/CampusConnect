# CampusConnect

A student resource hub built with HTML, CSS and JavaScript.

**Live site:** https://prateeksharma2300-tech.github.io/campusconnect/

## Features
- **Dashboard:** announcements, exam countdown and pending tasks
- **Study Library:** searchable resources filtered by subject
- **Student Tools:** SGPA calculator, attendance calculator and a to-do list
- **Events & Opportunities:** hackathons, internships, scholarships and free courses
- **Profile:** saved on your own device
- **Dark mode** and a responsive layout for mobile

## Built with
- HTML5
- CSS3 (Flexbox, Grid, media queries)
- JavaScript (DOM, events, localStorage)
- Hosted on GitHub Pages

## How to run locally
1. Clone the repository
2. Open the folder in VS Code
3. Right-click `index.html` and choose **Open with Live Server**

## What I learned
- Building a multi-page website from scratch
- Creating page content with JavaScript from arrays of objects
- Saving data in the browser with localStorage
- Publishing a project with Git and GitHub Pages
